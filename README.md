<h1>OPKSSH</h1>

<p>Connect to hosts with short-lived OpenPubkey SSH certificates after signing in with your identity provider</p>

</div>

<br />

## Overview

OPKSSH lets you connect to hosts with short-lived SSH certificates from [OpenPubkey SSH](https://github.com/openpubkey/opkssh), after signing in with your identity provider.

<br />

## Install

OPKSSH ships with [Termix](https://github.com/Termix-SSH/Termix). Admins can turn it on or off, update it or install it again from the Plugins tab. Want to see it first? Try the [demo](https://demo.termix.site/), any username and password works.

<br />

## Features

- Adds the OPKSSH auth type to hosts
- Sign in with your identity provider in the browser
- Certificates last 24 hours, so you sign in once a day
- Uses a pinned, checksum verified `opkssh` release
